## What Is TransTools

TransTools is a set of add-ins for Microsoft Office and related Windows programs, aimed at translators who already work in Word, Excel, PowerPoint, or AutoCAD. It does not try to become a full translation-memory suite. It solves the small, repeated chores that appear in files you already own: messy quotes, dual-column spreadsheets, hidden tags, and drawing text that would otherwise be easy to miss.

People look for TransTools Word add-in because a CAT grid is not always the right place for a single letter or a spreadsheet the client still wants in Excel. TransTools Excel dual columns keep that workbook structure. TransTools untranslatable hide is there so you do not translate invoice numbers or part codes. TransTools AutoCAD text is the same idea on a drawing you are allowed to edit.

TransTools stays light on purpose. You open the document you already keep, run the command you need, and return to writing. Students doing coursework in Word, freelancers with client Excel packs, and technical writers who also touch drawings on a PC they own can all use it without changing their whole toolchain.

## Starting with TransTools

Prerequisites: Microsoft Office on a PC you own, and a Word, Excel, or CAD file you are allowed to edit.

1. **Prepare:** Open the document you already received in Word or Excel, not a blank file from another job.
2. **Configure:** Enable TransTools Word add-in or TransTools Excel dual columns for that program, then glance at which commands match this file type.
3. **Test:** Run TransTools untranslatable hide on a short passage and confirm numbers or tags dim as expected.
4. **Refine:** If the pack includes drawings, open the CAD file you keep and try TransTools AutoCAD text on a single note.
5. **Apply:** Work the real document with the commands you need, then save back to the same client folder.
6. **Maintain:** Leave commands that belong to a different file type off this session so the ribbon stays readable.
